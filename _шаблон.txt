# ШАБЛОН ОПИСАНИЯ СЕТА
#
# Как пользоваться:
#   1. Скопируйте этот файл в ту же папку, где лежит mp3 сета.
#   2. Переименуйте его так же, как называется mp3, но с окончанием .txt
#      Например: set-01.mp3  ->  set-01.txt
#   3. Замените текст ниже на свой и сохраните файл.
#   4. Загрузите файл вместе с музыкой (рядом с mp3).
#
# Строки, которые начинаются с символа «#», сайт не показывает.
# Их можно оставить или удалить.
#
# Файл необязательный. Если его нет, у трека просто не будет описания.
#
# Правила:
#   - Всё, что написано ДО первой строки со временем, это описание.
#     Оно может быть в несколько строк и абзацев.
#   - Метка времени пишется на отдельной строке: время, пробел, название.
#   - Время: минуты:секунды (12:30) или часы:минуты:секунды (1:05:20).
#   - На сайте нажатие на метку перематывает сет на это время,
#     а на волне трека появляются точки с названиями меток.
#
# Ниже пример. Замените его своим текстом.

Здесь пишется описание сета: о чём запись, когда и где она сделана, под какое настроение.

Можно добавить второй абзац: например, что вошло в сет или кому он посвящён.
