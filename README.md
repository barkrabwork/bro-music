# Bro Music

Личный музыкальный плеер для брата: статический сайт (GitHub Pages) + музыка в Yandex Object Storage.

## Локальный запуск демо

```
cd C:\Claude_project\bro-music
python -m http.server 8000
```

Открыть http://localhost:8000. Простой сервер Python не поддерживает перемотку по Range, поэтому перемотка в демо может не работать локально; на GitHub Pages и в Yandex Object Storage она работает.

## Структура

| Файл | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js` | Сайт (плеер, подборки, плейлисты, избранное, таймер сна, волновая форма) |
| `fonts/`, `img/` | Шрифты (Permanent Marker для названия, Caveat для рукописного режима) и картинки темы PromoDJ (баннер и логотип). Шрифты с открытой лицензией OFL |
| `config.js` | Адрес музыки (`MUSIC_BASE_URL`), название сайта, внешний вид по умолчанию (`DEFAULT_SETTINGS`). При переходе на настоящий бакет меняется `MUSIC_BASE_URL` |
| `help.js` | Текст справки |
| `_шаблон.txt` | Образец файла описания для брата |
| `demo-tracks/` | Демо: сгенерированные тестовые треки, обложки и `tracks.json`. Перед передачей брату удалить |
| `tools/make-demo.py` | Генератор демо-треков (`python -I tools/make-demo.py`) |

## Формат tracks.json

```json
{"tracks": [{
  "id": "sets-2025/summer-set.mp3",
  "title": "Summer Set",
  "folder": "sets-2025",
  "duration": 3612.4,
  "peaks": [12, 40, 77],
  "cover": "sets-2025/summer-set.jpg"
}]}
```

`id` это путь файла в бакете. Папка становится подборкой. `title`, `folder`, `peaks`, `cover` необязательны: без них название берётся из имени файла, волна рисуется условная, а обложка ищется как `<имя трека>.jpg` рядом, иначе показывается заглушка. Скрипт загрузки сам подставляет в `cover` либо обложку трека, либо общую обложку папки: файл `cover.jpg` (`.png`, `.webp`) в той же или ближайшей папке выше.

## Страница трека и настройки

- Клик по названию трека (или по обложке и названию в нижней панели) открывает «Сейчас играет» с вращающейся пластинкой. На экране шире 1280 px это правая колонка, на телефоне полноэкранная панель.
- Ссылка `index.html#track=<путь трека>` выбирает трек при открытии (без автозапуска), а `&t=<секунды>` открывает его сразу на нужном моменте. Кнопка со ссылкой на странице трека копирует ссылку на трек или на текущий момент (если буфер обмена недоступен, показывается окно со ссылкой). Смена `#…` в адресной строке уже открытой страницы тоже переключает трек.
- Шестерёнка в верхней строке: тема (тёмная, чёрная, светлая, PromoDJ с баннером, логотипом и контактами), рукописный шрифт Caveat для левой, центральной и правой панелей (флажки), размеры заголовков и текста, цвета акцента и текста, фон (файл или ссылка) с затемнением. Настройки, плейлисты и избранное хранятся в браузере и не переносятся между устройствами. Фон-файл уменьшается до 1600 px и лежит в IndexedDB.

## Описание и метки времени (`.txt` рядом с треком)

`set-01.mp3` → `set-01.txt`. Сайт читает файл в момент открытия трека (без `tracks.json`), поэтому его можно править в любой момент. Кодировка UTF-8 (или Windows-1251, определяется сама).

- Всё до первой строки со временем это описание (несколько абзацев можно).
- Строка `мм:сс название` или `ч:мм:сс название` это метка. Клик по метке перематывает трек, на волне она видна точкой, при наведении показывается название.
- Строки, начинающиеся с `#`, не показываются. Текст после меток без времени показывается как примечание.
- Образец для брата: `_шаблон.txt`. Скрипт загрузки должен пропускать файлы, имена которых начинаются с `_`.

## Справка

Кнопка «?» в верхней строке. Текст лежит в `help.js` (разделы с абзацами, списками и примерами), править его можно без изменения логики. Раздел «Как добавить новые треки» нужно добавить, когда будет готов скрипт загрузки.

## Загрузка музыки: `upload-tool/`

Для компьютера брата (Windows). Не нужно устанавливать ничего вручную.

| Файл | Назначение |
|---|---|
| `setup.bat` | Один раз: скачивает `rclone` и `ffmpeg` в папку `bin` рядом (с проверкой контрольных сумм) |
| `settings.example.txt` → `settings.txt` | `REMOTE` (куда: `yc:имя-бакета`), `SOURCE` (папка с музыкой на компьютере), необязательные `BIN_DIR`, `RCLONE_CONFIG` |
| `upload.bat` | Загружает новые и изменённые файлы (mp3, обложки, `.txt`), пропуская файлы и папки на `_` и `.`, и пересобирает `tracks.json` в хранилище |
| `upload.bat rebuild` | Заново считает данные всех треков |
| `upload.bat clean` | Показывает файлы, которых нет в `SOURCE`, и удаляет их из хранилища только после ответа «ДА» |

Как это устроено: список треков берётся из содержимого хранилища (путь файла = id трека), поэтому музыку можно загрузить и вручную, а потом запустить `upload.bat`. Прежний `tracks.json` служит кэшем: данные (теги, длительность, волна из 240 столбиков) считаются только для новых или изменившихся файлов. Название = «Исполнитель — Название» из тегов mp3, при пустых или нечитаемых тегах берётся из имени файла. Обложка находится по имени (`.jpg`, `.jpeg`, `.png`, `.webp`). `tracks.json` и `.txt` грузятся с `Cache-Control: no-cache`.

Не загружать в репозиторий сайта: `upload-tool/bin`, `rclone.conf`, `settings.txt` (в самом репозитории сайта `upload-tool` вообще не нужен).
